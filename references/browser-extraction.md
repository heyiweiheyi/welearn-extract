# 浏览器提取流程

## 确认会话和范围

- 从 `https://welearn.sflep.com/` 或用户在该网站已打开的课程进入。遇到登录页时，交给用户完成正常登录。使用浏览器自身的会话，避免导出 Cookie、密码、令牌、验证码或浏览器配置文件。课程内嵌页面和资源来源以本次正常导航显示的结果为准。
- 数字教材可能嵌在课程页面里。进入教材自己的「目录」或「资源」面板，从所需单元核对资源名。目录节点可能只跳到课文位置，需要再打开音频控件或展开视频。等当前资源出现后再继续，避免把相邻条目的资源配错。

## 保存资源

- 使用页面的下载按钮、附件链接或浏览器的媒体保存功能。保存后核查文件确实是所需媒体或文档，避免把登录提示或错误网页当成资源。
- 播放器可能只暴露暂时的 `blob:` 地址。当前工具支持读取已加载的媒体资源时，可在用户的访问范围内查看该次正常打开或播放所加载的资源。只使用与已核对的条目对应、当前会话有权访问的媒体来源。对浏览器或工具不可见的资源，说明具体限制。
- 如果播放器提供可保存且允许下载的 HLS 流，使用支持 HLS 的下载方式，或用已安装的 FFmpeg 将流封装为单个文件。音频通常可保存为 M4A，视频通常可保存为 MP4。无损封装前确认轨道和编码兼容。不要把清单、分片或 `blob:` 地址当作最终文件。
- 签名 URL 或会话相关的流地址有时只在浏览器中有效。把它们留在当前浏览器会话，交付本地文件。遇到 DRM、下载限制、权限错误或账号警告时停止这条路径，不尝试绕过。单纯的加载超时可以在页面状态正常时重试一次。教材提示资源仍在解析时，将该条标为未取得。

## 核对交付

- 每次查看一条资源，记录标题、单元和播放器时长。用对应的播放数据、标题或时长核实关联。一个媒体在多道题下出现时，可以保留一份，但应先确认来源一致。
- 通过可用的本地播放器或媒体检查工具确认轨道、文件大小和时长。交付前对照目录，列出缺项。用户要求现有字幕时，优先寻找播放器的字幕轨或平台提供的字幕文件。用户要求自动生成时，使用合适的转写方式，保持文件名与时间轴对应。
