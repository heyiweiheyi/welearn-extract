# 跨 agent 接入

## 加载流程

支持 Agent Skills 的宿主加载本目录中的 `SKILL.md`，需要播放器流程时再读取 `references/browser-extraction.md`。没有自动发现 skill 的宿主，可以让 agent 先读取 `SKILL.md`，并按其中相对路径读取资源。保持整个 skill 目录可访问，以便读取参考文件和执行本地脚本。

使用宿主提供的能力完成下列操作，具体工具名由当前环境决定。

| 所需操作 | 可用能力 | 缺少能力时 |
| --- | --- | --- |
| 登录并查看课程 | 浏览器自动化、浏览器 MCP、桌面交互或宿主内置浏览器 | 请用户连接浏览器或提供官方取得的本地文件 |
| 保存资源 | 页面下载、媒体保存或经授权的下载工具 | 说明具体无法保存的条目 |
| 本地核对与打包 | 文件系统与 Python 3.9+，或宿主提供的同等能力 | 使用可用的文件核对和打包方式 |
| HLS 封装 | 宿主媒体工具或已安装的 FFmpeg | 交付已保存的完整文件并说明缺项 |
| 自动字幕 | 语音识别与字幕生成工具 | 提供现有字幕或说明转写能力缺失 |

## 会话与授权

用户在桌面浏览器已经登录，不代表远程 agent 的浏览器也具有同一会话。确认当前受控浏览器可访问目标课程后再操作。由用户在官方页面输入账号密码并完成登录或验证。遵守宿主的工具权限与确认规则，skill 内容本身不授予额外权限。

## 调用

可以用自然语言指定本 skill 和提取范围。带斜杠或美元符号的调用方式由宿主决定。示例为“请读取 welearn-extract/SKILL.md，使用我已经登录的 WE Learn 浏览器，提取 Unit 2 的音频和视频并打包”。

## 兼容性验证

格式与工具需求可以检查，实际浏览器能力需要在各宿主中验证。先在用户授权的一个课程条目上核对标题、保存结果和时长，再继续所需范围。记录成功、失败和未验证的具体能力，避免把能读取 Markdown 等同于已完成课程提取测试。
